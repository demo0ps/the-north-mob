# DECISIONS — The North Mob demo

Anything a future developer would ask "why?" about.

| # | Date | Decision | Why |
|---|---|---|---|
| 1 | 2026-10-10 | Static site, no backend; admin state in browser localStorage with export/import | Prospect demo, not signed. Cost doctrine: scale-to-zero, R0. Real orders need a backend only after signing. |
| 2 | 2026-10-10 | Palette: black base + Mob Red #DE0304 + volt #C8FF2E | Red sampled programmatically from client photo 2 (dominant accent). Black dominates all 9 client photos, so a dark site makes their photos sit seamlessly. Volt added for the "energetic, vibrant" brief. |
| 3 | 2026-10-10 | Unconfirmed Instagram handles never link out | A guessed handle can point at a stranger's account. Buttons render disabled until the owner confirms in admin. |
| 4 | 2026-10-10 | AI-generated hero, merch mockups, gig posters and backdrops; labelled illustrative | Client photos are 399×501-ish: fine in grids, too soft for full-width heroes. Owner instructed "generate more". |
| 5 | 2026-10-10 | Money as integer cents; simulated checkout, labelled on-screen | Correct money handling from day one; no real payment in a demo, and no provider chosen. |
| 6 | 2026-10-10 | No external fonts, CDNs or scripts | Preview environment has no network; the site must be faithful offline. System font stack with Impact-family display fallback. |
| 7 | 2026-10-10 | Renamed client .jfif uploads to .jpg | JFIF is JPEG; some servers send .jfif as octet-stream which forces download instead of rendering. |
| 8 | 2026-10-10 | Placeholder sponsors shown as labelled "partner slot" cards, never invented company names | Never imply fake endorsements. |
| 9 | 2026-10-10 | This project supersedes The Box House as the active brief | Owner instruction: "new project". Box House profile and docs retained in `docs/profiles/`. |
| 10 | 2026-10-10 | Placeholder enquiry/contact emails use `.example` TLD | Reserved TLD, cannot accidentally reach a real address. |
| 11 | 2026-10-10 | Checkout success gets a "Done — back to the site" button, and closing checkout after success also closes the cart drawer | Found in testing: after ordering, the customer was stranded on an open modal/empty drawer. |
| 12 | 2026-10-10 | UI verified in headless Chromium via Playwright, with system libs fetched as .debs and extracted locally | Sandbox has no root; `libnspr4`/`libnss3`/etc. were missing. Extracted under /tmp with LD_LIBRARY_PATH — no system changes. Test: `tools/verify.py`. |
