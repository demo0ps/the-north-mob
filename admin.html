What this admin is

A pitch demo of the management view: order tracking, enquiry handling, catalogue, gigs, links and site text — all running in the browser. When the Mob signs, this maps 1-to-1 onto a real backend (suggested: Supabase free tier) with logins, and nothing about the workflow changes.
